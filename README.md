# Weather App 🌦️

A responsive weather application built using React and OpenWeather API.

## 🔥 Features
- Search weather by city
- Displays temperature, humidity, wind speed
- Shows "feels like" temperature
- Weather condition icons
- Error handling for invalid cities
- Dark mode toggle

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6)
- OpenWeather API
- CSS

## 🚀 Live Demo
https://weather-app-gilt-five-96.vercel.app

## 📌 How It Works
User enters a city → API fetches real-time data → UI updates dynamically.
